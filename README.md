# Iran IP List

I provide a monthly update of IP addresses belonging to Iran here. I use five
different sources and then carefully combine them together to make sure all
IPs are included. IPs are provided in optimized CIDRs, in both plain CIDR
and MikroTik RouterOS firewall format.

<br>

## Files

- `Iran-IP-CIDR.txt` — plain CIDR format, one range per line.
- `IranIP.rsc` — MikroTik RouterOS firewall address-list format.

<br>

## Sources

Compiled from five independent IP range sources, then merged and optimized
to remove overlaps and redundancy while ensuring full coverage.
List of sources: [1](https://www.ipdeny.com/ipblocks/) - [2](https://github.com/ipverse/country-ip-blocks/tree/master/country/ir) - [3](https://github.com/ipverse/geo-ip-blocks/tree/master/country/ir) - [4](https://www.ip2location.com/free/visitor-blocker) - [5](https://github.com/KAJOOSH/iran-ip-database/tree/main/output)

<br>

## Disclaimer

This list is provided as-is for informational and network configuration
purposes. Accuracy depends on the underlying sources and may change over time.
